# CPS Mental Gym & Systems Thinking Frameworks

Un entorno agnóstico e interactivo para ejercitar el pensamiento sistémico, la resolución de problemas complejos (CPS) y modelos mentales de alto nivel.

## 🧠 Marcos Incluidos
- **Untools.co:** Modelo del Iceberg, First Principles, Inversion, Decision Trees.
- **The Systems Thinker:** Causal Loops, Leverage Points, Shifting the Burden.
- **Cynefin Framework:** Simples, Complicados, Complejos y Caóticos.
- **Factor X & Sesgos Cognitivos:** Kahneman, Tversky & Recuenco.
